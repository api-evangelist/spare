## API Reference
- [Hosting](https://docs.tryspare.com/reference/hosting-1.md): Spare has a sandbox and production environment, and it is important for you to set the host for API calls right.
- [Json web key set](https://docs.tryspare.com/reference/get_api-v1-0-authentication-jwks.md): **Unique resource name :** api_authentication.v1.cert.jwks              A set of Json Web Keys (JWK) based on <a href="https://www.rfc-editor.org/rfc/rfc7517" target="_blank">rfc7517</a>. - To verify the tokens (access_token or refresh token) signature. - To verify webhooks x-signature header.
- [Create an API token](https://docs.tryspare.com/reference/get_api-v1-0-authentication-token.md): **Unique resource name :** api_authentication.v1.token
- [Refresh API token](https://docs.tryspare.com/reference/get_api-v1-0-authentication-refresh.md): **Unique resource name :** api_authentication.v1.refresh
- [Get an account by id](https://docs.tryspare.com/reference/get_api-v1-0-ais-account-get-1.md): **Unique resource name :** ais.v1.account.get              **Important!:**              The permissions bellow are required on the consent: - `ReadAccountsBasic` - `ReadAccountsDetail`
- [List accounts](https://docs.tryspare.com/reference/get_api-v1-0-ais-account-list-1.md): **Unique resource name :** ais.v1.account.list              **Important!:**              The permissions bellow are required on the consent: - `ReadAccountsBasic` - `ReadAccountsDetail`

- [Get account balance history](https://docs.tryspare.com/reference/get_api-v1-0-ais-balance-history-1.md): **Unique resource name :** ais.v1.balance.history              **Important!:**              - The maximum allowed date range period is one year. - `toDate` need to be greater than `fromDate`              The permissions bellow are required on the consent: - `ReadAccountsBasic` - `ReadAccountsDetail` - `ReadBalances` - `ReadTransactionsBasic` - `ReadTransactionsDetail` - `ReadTransactionsDebits` - `ReadTransactionsCredits`

- [Verifies if the provided IBAN and ID match and retrieves the beneficiary name associated with the IBAN.](https://docs.tryspare.com/reference/post_api-v2-1-av-accountverificationpro-match.md): **Unique resource name :** av.v2.1.account_verification_pro.match            **Important!:**- The IBAN must be a valid KSA IBAN.- The `idValue` must be valid according to the required format (e.g., National ID, Iqama number, or Registration number).- The request validates the IBAN and ID match and also fetches the associated beneficiary name.
- [Verifies a corporate account by matching the IBAN with the provided Company Registration (CR) or Unified National Number (UNN)
and combines it with Beneficiary Verification.](https://docs.tryspare.com/reference/post_api-v2-1-av-accountverificationpro-corporate.md): **Unique resource name :** av.v2.1.account_verification_pro.corporate              **Important!:** - The IBAN must be a valid KSA IBAN. - The CR or UNN must be valid 10-digit numbers. - The beneficiaryName will be verified against the account holder name.
- [Verifies if the account ID matches the provided identification details.](https://docs.tryspare.com/reference/post_api-v2-0-av-accountverification-idmatch.md): **Unique resource name :** av.v2.account_verification.id_match              **Important!:** - The provided IBAN must be a valid KSA IBAN. - The `idValue` must be a valid KSA national ID, Iqama number, or registration number. - Ensure the request model adheres to the required format for successful validation.
- [Verifies a corporate account by matching the IBAN with the provided Company Registration (CR) or Unified National Number (UNN).](https://docs.tryspare.com/reference/post_api-v2-0-av-accountverification-corporate.md): **Unique resource name :** av.v2.account_verification.corporate              **Important!:** - This endpoint is designed for clients who may not know which ID type to use and want to send all information for comprehensive validation. - The IBAN must be a valid KSA IBAN.
- [Retrieves the name of the beneficiary associated with the specified IBAN.](https://docs.tryspare.com/reference/post_api-v2-0-av-beneficiaryverification-match.md): **Unique resource name :** av.v2.beneficiary_verification.match              **Important!:** - The IBAN must be a valid KSA IBAN. - The request model must include all required details for successful beneficiary retrieval.
- [Verifies if the provided IBAN and ID match and retrieves the beneficiary name associated with the IBAN.](https://docs.tryspare.com/reference/post_api-v2-0-av-commonverification-match.md): **Unique resource name :** av.v2.common_verification.match              **Important!:** - The IBAN must be a valid KSA IBAN. - The `idValue` must be valid according to the required format (e.g., National ID, Iqama number, or Registration number). - The request validates the IBAN and ID match and also fetches the associated beneficiary name.
